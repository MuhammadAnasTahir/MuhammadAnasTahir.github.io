# Project notes

This site is currently plain HTML/CSS/JS (no React, no build tooling, no npm). The note below only applies if/when this project (or a future one) moves to React + Tailwind.

- When building React/Tailwind UI, prefer shadcn primitives (via the shadcn MCP server) over hand-rolling components that already exist in the registry. Search the registry first before writing a component from scratch.
